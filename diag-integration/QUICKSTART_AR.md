# تشغيل GITM AutoDiag

1. افتح «المحول»، اختر USB أو عنوان TCP لمحول Wi-Fi أو محول Bluetooth مقترن، ثم اتصل. لا يُرسل البرنامج أوامر إلى أجهزة USB مجهولة تلقائيًا.
2. افتح «التشخيص الذكي» أو «البيانات الحية»، واضغط «فحص». المساحة الجديدة تدعم محولات ELM/STN عبر CAN OBD فقط. تعرّف الوحدة برقم المجيب، لا بتخمين أنها ABS أو Airbag.
3. راجع تبويبات الملخص والأعطال والجاهزية ولحظة العطل. «بيانات غير متاحة» أو نتيجة جزئية لا تعني خلو السيارة من الأعطال.
4. اختر حساسًا متاحًا بعد الفحص، ثم ابدأ البيانات الحية. الرسم يعرض وحدة واحدة ويذكر اسمها ووحدة القياس. تسجيل CSV يتوقف عند 10000 سجل؛ التصدير يحفظ القراءات وأوقاتها وأخطاءها.
5. صدّر تقرير HTML للمراجعة والطباعة من المتصفح، أو JSON للاحتفاظ بالأدلة. التقارير تحفظ محليًا ولا ترسل بيانات السيارة للسحابة.
6. مسح الأعطال يتطلب موافقة صريحة، وقراءة RPM صفر من جميع المجيبين، وحفظ تقرير قبل المسح. قد يعيد ضبط جاهزية الانبعاثات ويزيل بيانات لحظة العطل، ولا يزيل الأكواد الدائمة تلقائيًا.
7. «تعريفات ECU» توفر قراءة ملف JSON موثق ومطابق للمركبة. تحتاج العناوين والتعريفات الصحيحة؛ لا توجد قواعد OEM كاملة مضمنة ولا برمجة عامة لكل السيارات.

للتدريب دون سيارة: شغّل `python3 /opt/gitm/obd_simulator.py` باستخدام Python الذي يحتوي مكتبات البرنامج، ثم اتصل بـ `127.0.0.1:35000` كعنوان Wi-Fi/TCP. هذا محاكي محلي فقط؛ تظهر علامة SIMULATOR في النتائج والتقارير. ليس إثباتًا لدعم سيارة حقيقية.
