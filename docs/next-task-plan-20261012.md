# المهمة التالية — ملف السيارة وأمر الإصلاح

تبدأ بعد إغلاق دفعة الاستقرار والتحقق من المثبت واللقطات. لا تغيير لسطح المكتب أو القائمة الجانبية ولا تكرار للحاسبة والكاميرا وPDF داخل AutoDiag.

1. ملف سيارة موحد: معرف داخلي ثابت، عميل واحد وعدة سيارات، لوحة ورقم VIN عند توفره، سجل زيارات وتقارير ومرفقات. لا يُستبدل VIN المدخل تلقائيًا بنتيجة غير مؤكدة.
2. أمر إصلاح: رقم، سيارة وعميل، شكوى وملاحظات فني، الأعمال والقطع والتقدير والحالة. حالات واضحة: مسودة، قيد التشخيص، بانتظار الموافقة، قيد الإصلاح، إعادة فحص، مكتمل، ملغى.
3. ربط الفحص بالأمر: لقطة نتائج ثابتة مع مصدرها وتوقيتها. المحاكاة تبقى منفصلة عن سجل سيارة فعلية، ولا يُعاد نسب تقرير لسيارة أخرى.
4. التحويل إلى فاتورة: نقل الخدمات والقطع والسياق دون تكرار الإدخال، حساب Decimal بالدرهم MAD، خصم وضريبة قابلة للإعداد، حفظ حالات الفاتورة وPDF.
5. مقارنة قبل/بعد: مقارنة تقارير من السيارة والوحدات نفسها، مع توضيح القراءة الناقصة وعدم مساواتها بالنجاح.
6. نسخ احتياطي واستعادة محلية: تصدير قاعدة الورشة والمرفقات مع فحص الاتساق، معاينة الاستعادة قبل استبدال البيانات. لا مزامنة سحابية أو إرسال بيانات العملاء تلقائيًا.

معيار القبول: عميل بسيارتين، فتح أمر وإرفاق فحص حقيقي المصدر أو محاكي موسوم، حفظ وإعادة فتح، إنشاء فاتورة صحيحة، عدم تكرار السجلات عند النقر مرتين، اختبار استعادة وRTL وخط كبير، وتوثيق لقطات من البرنامج الفعلي. البرمجة والاختبارات النشطة ووظائف OEM المتخصصة خارج هذه المهمة حتى تتوفر تعريفات وإجراءات وتوافق مثبت.
