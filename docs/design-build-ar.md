# GITM OS — إصدار المظهر الأول
نسخة Live من Ubuntu 24.04 للمعمارية x86_64، بسطح مكتب GITM وتطبيق AutoDiag المستقل.
## التغييرات
مظهر نهاري وداكن محفوظ لكل مستخدم، وضع أداء وتقليل حركة، بحث الإعدادات، Esc لإغلاق لوحة التحكم، Ctrl+F لبحث التطبيقات، وإصلاح تشغيل المتصفح بتحميل سياسته قبل الجلسة.
التطبيقات العشرة تظهر دون تمرير أو شروح. حلقات RAM والتخزين داخل إطار مربع. لوحة التحكم تظهر بالسهم، وأيقونات الاتصال والبطارية تستجيب للحالة الفعلية.
## التحقق
اجتاز البناء 38017305438 إقلاع BIOS وUEFI وتشغيل Falkon تحت سياسته. الألبوم يحتوي 60 لقطة جديدة من ISO نفسه. لم ينفذ الاختبار تثبيتًا على القرص أو تعديلات على سيارة.
هذه تحسينات واجهة Qt الحالية؛ لا تدعي اكتمال نقل Android SystemUI أو الانتقال إلى QML/KWin. وظائف السيارات المتقدمة تحتاج بيانات ECU وعتادًا واختبارات محددة.
