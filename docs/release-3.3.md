GITM OS 3.3 integration preview: Ubuntu 24.04 amd64 with the custom GITM desktop and integrated native AutoDiag. Actual BIOS and UEFI guest desktop boot must pass before this release is uploaded. Includes SHA-256 and actual boot/Qt screenshots.

Includes workshop records, customers and invoices, signed application update/rollback engine, general Linux applications, OBD read paths, ECU definition import, split diagnostics and separate-adapter secondary sessions, and authenticated Cloudflare UI.

This is a development preview, not universal automotive coverage. OEM coding, active tests, maintenance procedures, TPMS/ADAS/key and EV-specific functions still require their hardware/definitions and validation. Cloud sign-in/provider response, disk installation, physical adapters and whole-system rollback are not certified by the boot test. See docs/feature-coverage.md in the repository.

The original public update trust key is retained. No provider secrets or signing private keys are bundled.
